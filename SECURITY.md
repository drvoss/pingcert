# Security Policy

## Supported versions

pingcert is pre-1.0 software. Security fixes are applied to the latest source
revision; older revisions are not supported.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting feature when it is available.
If it is not available, open an issue asking for a private contact channel, but
do not publish exploit details, credentials, private hosts, or certificate
material.

pingcert performs DNS, ICMP, TCP, and TLS diagnostics. Only test targets and
networks you own or are authorized to test.
